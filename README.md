VITyarthi project for Python essentials.

● Project title : 
Personal Finance Manager using Tkinter and CSV

● Overview of the project :
This project is a GUI-based personal finance tracking system built with Python and Tkinter. It allows users to record, update, view, search and delete financial transactions. All data is stored in CSV files so the project remains lightweight, portable and easy to understand.

● Features :
- Add new transaction entries with unique IDs
- Modify existing transaction details
- Search for transactions using their ID
- Delete transactions with confirmation
- View all transactions in a scrollable window
- Tkinter-based graphical interface for all operations

● Technologies/tools used :
Python
Tkinter for the GUI
CSV module for data handling
Datetime module for timestamps

● Steps to install & run the project :
1. Install Python (version 3.x).
2. Ensure the following modules are available:
tkinter
csv
datetime
These are included with standard Python installations.
3.Download or copy the project files, including:
Sourcecode.py (Tkinter GUI)
transactions.csv
4.Open a terminal or command prompt in the project directory.
5.Run the application using:
python Sourcecode.py

● Instructions for testing :
Run the program and use the “Add Entry” option to create sample transactions.
Use “View All Entries” to confirm they are saved correctly.
Test “Modify Entry” by providing an existing ID and updating the category or amount.
Use “Search Entry” to find a transaction by ID.
Test “Delete Entry” to ensure the row is removed.
