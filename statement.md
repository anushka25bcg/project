- Problem Statement

Managing daily expenses often becomes messy when handled informally. People may forget entries, lose track of spending patterns or miscalculate how much they’ve spent in a given month. This project aims to provide a simple tool for recording, checking, updating and managing personal financial transactions without relying on heavy databases or complex applications.

- Scope of the Project

The project focuses on basic personal finance tracking through a lightweight GUI. It allows users to enter transactions, store them in CSV files, and view or edit entries as needed. It does not include advanced financial analytics, charts or multi-user functionality. The scope remains intentionally simple so users can understand, modify and extend the program as required.

- Target Users
1. Students who need a quick way to manage daily spending
2. Individuals who prefer simple tools over full budgeting apps
3. Beginners learning Python who want to explore GUIs and file handling
4. Anyone who wants an offline, portable finance tracker

- High-Level Features

Graphical interface for all operations

Create, read, update and delete transactions

CSV-based storage requiring no database setup

Search functionality for quick lookup

Scrollable window to view all entries
